# 海纳 · 供应链协同平台（SCC Web）

Vue 3 + TypeScript + Element Plus 前端原型，参考 `sscrm-admin-web-next` 的后台视觉和组件化做法。包含供应商门户、业主管理端和采购审核端的首期演示页面。

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 `http://127.0.0.1:3201/scc/`。执行 `pnpm build` 检查类型并构建；仓库根目录的 `pnpm build` 会组装多子系统演示站。

## 演示范围

- 演示登录与角色切换；首页总览；供应商名录和详情；2027 年度资料编辑、联系人、证照、提交；账号与子账号；采购审核。
- 后台右上角“系统配置”提供主题色、页面显示、多页签和页面状态缓存设置。页面设置保存在本浏览器，页签保存在本次浏览器会话；“清空前端缓存”仅清除 SCC 原型的本地数据与设置并返回登录页。
- 所有内容都是**虚构演示数据**，交互保存在浏览器 `localStorage`。点击左下角“重置演示数据”可恢复初始状态。短信验证码在原型中固定显示为 `123456`，没有发送短信；上传只保存文件名和元数据，没有上传 OSS。
- 未接入后端、数据库、真实身份认证、短信或支付服务；原型上的审核、账号操作和权限切换不具备生产安全语义。

## 前端约定

- `src/shared/`：布局、设计变量和可复用的 UI 约定。PSI、PAY 将来可按版本复用视觉规范，避免跨业务复制状态逻辑。
- `src/domain/`：供应商、联系人、资质、账号等类型和模拟数据操作。后续用 API 适配器替换数据来源，页面不直接依赖 `localStorage`。
- `src/views/`：按页面职责组织；路由与菜单分别由 `src/router.ts` 和布局维护。
- 供应商编码始终是字符串；演示新增号按七位、步进 10 分配，旧异常编码原样保留。
- 登录页与后台共用 `SiteCopyright`。备案号按业主提供的信息展示；公安图标优先使用备案平台图片，加载失败时使用本地备用图标。正式上线前需核对旧 EDI 的版权原文及备案图标文件。

本项目独立于 `../../docs/` 文档仓库。正式 API 契约、授权方式、上传流程与数据迁移以评审后的设计方案为准。
